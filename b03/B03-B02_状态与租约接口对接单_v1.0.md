## 0. 一句话目的

B03 提供**状态持久化、租约、事件去重、快照与检查点**能力；B02 独占**状态迁移决策**。本单用于把接口签名和调用约束钉死，避免双写者、重复执行和过期回调推进状态。

## 1. B03 向 B02 提供什么

### 1.1 原子状态接口（B02 独占写入）

| 接口 | 签名要点 | 返回 | 约束 |
|---|---|---|---|
| `get_task_state` | `(task_id)` | `ExecutionState` | 只读；含 `state` / `rev` / `attempt_id` / `input_snapshot_ref` |
| `cas_state` | `(task_id, expected_rev, next_state, *, attempt_id, input_snapshot_ref, reason=None)` | `CasResult` | `rev` 不匹配即拒绝；B02 之外无写入者 |

### 1.2 租约接口（资源队列 / 写入范围）

| 接口 | 签名要点 | 用途 |
|---|---|---|
| `acquire_lease` | `(resource_key, *, task_id, attempt_id, ttl_seconds, idempotency_key)` | 派发前占用；按 `write_scope` 冲突检测 |
| `renew_lease` | `(lease_token, ttl_seconds)` | 长任务续期 |
| `release_lease` | `(lease_token)` | 完成或取消时释放 |
| `reclaim_expired_leases` | `(now)` | 恢复时回收过期租约，避免重派冲突 |

### 1.3 快照与事件接口

| 接口 | 签名要点 | 用途 |
|---|---|---|
| `freeze_input_snapshot` | `(task_id, *, spec_version, contract_version, plan_version, dependency_artifact_refs)` | 派发前冻结输入基线 |
| `get_snapshot` | `(ref)` | 读取快照（含 `valid`） |
| `verify_snapshot_still_valid` | `(ref)` | 验收前核对；无效不得置 `SUCCEEDED` |
| `invalidate_affected` | `(change_ref)` | 规格/产物变更时批量失效，返回受影响的 `SnapshotRef` |
| `append_event` | `(event)` | `event_id` 幂等；重复事件只记录一次 |
| `list_events` | `(after_event_id, limit)` | 按序拉取事件，供恢复与追溯 |

### 1.4 检查点接口

| 接口 | 用途 |
|---|---|
| `write_checkpoint(cp)` | 记录计划版本、任务状态、`processed_event_ids`、产物清单、租约 |
| `load_checkpoint()` | 恢复时载入；对 `RUNNING` 尝试先核实再决定是否重派 |

## 3. 状态迁移对照（B03 按此持久化，决策权在 B02）

| 迁移 | 触发条件 | B03 记录 |
|---|---|---|
| `PENDING → READY` | 前置全部 `SUCCEEDED` 且输入版本有效 | 依赖检查通过 |
| `READY → RUNNING` | 租约获取 + 快照冻结 + 派发意图已持久化 | `attempt_id`、起止时间 |
| `RUNNING → REVIEWING` | 收到匹配当前 attempt/快照的候选产物 | 候选提交引用 |
| `RUNNING → FAILED` | 超时 / 工具错误 | 错误与尝试历史 |
| `REVIEWING → SUCCEEDED` | 证据齐全 + 快照仍有效 | `accepted_commit`、`valid=true` |
| `REVIEWING → FAILED` | 缺文件 / 缺证据 / 校验失败 | 失败证据与 `rev` |
| `FAILED → PENDING/READY` | 允许修复 | 保留原失败历史 |
| `SUCCEEDED → PENDING` | 输入变更或回归，撤销有效性 | 失效原因 |

## 4. 分歧处理

- 接口语义分歧登记 `objection_id`，按共同协议最多两轮定向修订；六人确认前不自行改基线。
- 涉及 S1/C1、验收标准或范围的歧义升级 B01，不在实现中临时补规则、不降低门槛。
- 接口变更需同步所有消费方（B04/B05/B06），并在新提交上重跑受影响检查。
