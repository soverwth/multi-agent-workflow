## 2 实验环境与执行方式

本次环境：Windows、Python 3.14.3、pytest 9.1.1、jsonschema 4.26.0、Flask 3.1.3、argon2-cffi 25.1.0。完整 Python 版本、依赖版本和运行命令记录在包内 evidence。测试与四个示例均在归档的 `project` 目录执行，PYTHONPATH 指向该目录的 src，启用 PYTHONDONTWRITEBYTECODE，关闭 pytest 自动插件与 cacheprovider，避免把原工作区代码或缓存当作交付结果。

Windows 原有 asyncio 测试依赖本机回环，实际执行环境允许本机通信。Git、SQLite、文件和进程助手均为本地测试资源；没有调用真实模型、下载镜像或启动 Docker。

从项目目录复现：

```powershell
python -m pip install -e ".[test]"
python -m pip install -r src/b04/reference_backend/requirements.txt
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD = "1"
python -u -m pytest -q
$env:PYTHONPATH = (Resolve-Path .\src).Path
python examples/model_adapter_demo.py
python examples/agent_runner_demo.py
python examples/tool_executor_demo.py
python examples/reference_backend_demo.py
```
